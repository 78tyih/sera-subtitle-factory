三条硬规则The Three Hard Rules

写进类型与 CSS，不是口头约定enforced in types & CSS, not by convention
RULE #1

永远单行Always single-line

`maxLines: 1` 是类型字面量，`white-space: nowrap` 写死在 CSS。超宽不换行——重新分段。左边是错误示范（两行，已被产品禁止），右边是正确做法。`maxLines: 1` is a type literal; `nowrap` is hard-coded. Overflow never wraps — it re-segments. Left: forbidden two-liner. Right: the rule.

RULE #2

跟着声音走Voice-driven states

每个词带 start / end。任一时刻 currentTime 决定词的状态，所有动效围绕状态设计：Every word carries start/end; currentTime alone decides state, and every motion is designed around it:

RULE #3

不推挤邻词Never push neighbors

active / 强调只改 `transform` 与 `color`，不改 layout 尺寸——整句永远不左右跳动。看演示：数字放大时基线网格纹丝不动。Active/emphasis change only transform & color, never layout — the line never jumps. Watch: the number scales, the baseline grid doesn't move.
